# Günay 🤍 — Sevgi Saytı

Günay üçün hazırlanmış romantik, animasiyalı sevgi saytı.

## Xüsusiyyətlər
- ✨ Uçan ürəklər və işıq effektləri
- 💗 Canlı ürək animasiyası
- 🎵 Musiqi oynadıcı (music.mp3 əlavə edin)
- 📱 Mobil uyğun dizayn
- 🌙 Romantik tünd-çəhrayı tema

## GitHub Pages-ə yerləşdirmək

1. Bu qovluğu GitHub-a yükləyin (yeni repository yaradın)
2. Repository Settings → Pages → Source: `main` branch / root
3. Bir neçə dəqiqə sonra sayt aktiv olacaq:
   `https://USERNAME.github.io/REPO-ADI`

## Musiqi əlavə etmək

1. Sevdiyiniz romantik mahnını `music.mp3` adı ilə eyni qovluğa qoyun
2. Saytı yeniləyin və yuxarı sağdakı 🎵 düyməsinə basın

## Fayllar
- `index.html` — əsas səhifə
- `style.css` — stillər və animasiyalar
- `script.js` — ürəklər və musiqi
- `music.mp3` — (özünüz əlavə edin)
